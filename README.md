# HPI Talents, proposition de refonte

Maquette statique destinée à GitHub Pages.

## Principe de cette version

Cette version repart directement de la V9 et conserve son identité graphique : palette prune, mauve, ivoire et or, hero en deux colonnes, visuel principal, typographies Cormorant Garamond et Outfit, cartes, ornements, animations et footer sombre.

Les corrections portent sur le contenu et l'arborescence, pas sur une nouvelle direction graphique.

## Corrections intégrées

- contenu principal réaligné sur les informations publiques de HPI Talents
- navigation élargie et menus déroulants
- pages et sous-pages ajoutées sans remplacer le graphisme de la V9
- réseaux sociaux et plateformes de podcasts complétés dans le footer
- chiffres du réseau et informations de contact corrigés
- plan du site pour contrôler la couverture
- aucun tiret cadratin ou demi-cadratin dans les fichiers texte
- formulaire de contact neutralisé dans la maquette
- noindex et robots.txt pour éviter toute confusion avec le site officiel
